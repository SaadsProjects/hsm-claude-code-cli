HSM Agent Architecture

How /schedule-labor and /review-inventory each move through a persona-scoped subagent and the hsm MCP server's deterministic tools before a gate decides whether the write actually reaches HSM — and how the same gate pattern protects a git commit.

deterministic / authoritative — a REST call, a rules-engine check, a lint run: fixed logic, not model judgment
gate — needs approval — a hook or permission rule that can block the step regardless of what the agent or a human decided
