# Tech Stack Decisions — U1 secret-fail-closed

## Sources

- Code knowledge base `technology-stack.md` (Python 3.10+, standard library first, pytest, ruff, hash-pinned locks)
- `memory/team.md` Code Style; `memory/project.md` Code Style (`auth.py` is standard library only)
- `functional-design-questions.md` Q3 (bash dev-secret script); `nfr-requirements-questions.md` Q1, Q2

| Concern | Choice | Rationale |
|---------|--------|-----------|
| Secret reading, validation, burned-value check, `.env.local` loader | Python standard library (`os`, `hashlib`, `hmac`, `pathlib`) in `mock_hsm/auth.py` | `auth.py` must stay standard library only (project rule); it is shared by the dashboard, backend, hook and MCP server |
| Error type | `SecretMissingError`, a `RuntimeError` subclass (not a `TokenError`), carrying a `reason` attribute | Contract C1; keeps the 401 path from swallowing it (functional-design review item R-01) |
| Dev-secret script | Bash (`scripts/dev-secret.sh`), with the value generated by Python's `secrets.token_urlsafe(32)` (43 characters, 256 bits) | Q3; matches the existing `start_mock_server.sh` style |
| Start script length check | Delegate validation to Python (`require_secret()`) rather than counting bytes in bash | Avoids character-versus-byte mistakes (functional-design review item R-05); keeps one rule |
| Backend port | A `--port` option read by `mock_hsm.server`'s `__main__` (default 8770), passed through by the start script | Lets tests use a free port (functional-design review item R-02) |
| File mode | `umask 077` before writing `.env.local` | Q2 |
| Tests | pytest, existing fixtures and subprocess pattern; a generated secret set in `tests/conftest.py` | team.md Testing Posture |
| New dependencies | None | NFR7.1 |
