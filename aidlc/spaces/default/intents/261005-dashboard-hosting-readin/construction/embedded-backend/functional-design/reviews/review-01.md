### Summary

The design is well structured and covers all the acceptance criteria. But the default audit path (BR3.2) conflicts with how the audit module narrows its parent directory, which would break audited writes on any normal host. The "unwritable path fails the start" rule also has no detection mechanism, because `configure()` never raises. Fix R-01 and R-02, and tighten R-03 and R-04, before this is implementable without guessing.
